# Загрузка документов кандидатов: выпуск

Выкатывать одновременно `backend/services/database-service` и `frontend`; запустить HR Huey worker, который регистрирует `hr.candidate_documents.purge_drafts`. Миграция `migrations/candidate_documents.sql` применяется при старте database-service и добавляет таблицы сессий и черновых файлов. Проверить её выполнение по логам до открытия формы кандидатам.

В S3 применить lifecycle-конфигурацию из `backend/docs/candidate-documents-s3-lifecycle.json` к приватному бакету документов. Она удаляет **только** объекты с префиксом `candidate-docs/` и тегом `status=draft` через 3 дня; отправленные копии получают тег `status=submitted`. Фоновый worker очищает просроченные черновики раз в час и оставляет их в очереди при ошибке удаления из S3. Lifecycle — дополнительная страховка от оставшихся объектов. Провайдер S3 должен поддерживать object tags, `CopyObject`, `DeleteObject` и lifecycle-фильтр `And` с `Tags`.

Задать существующие секреты `S3_BUCKET`, `S3_ACCESS_KEY_ID`, `S3_SECRET_ACCESS_KEY`; при необходимости `S3_ENDPOINT_URL` и `S3_REGION`. Новых обязательных секретов нет. `CANDIDATE_DOCS_DRAFT_TTL_HOURS` имеет значение 72 по умолчанию; если его меняют, lifecycle-срок должен быть не меньше TTL сессии. Публичную ссылку выдавать только кандидату; `session_token` равносилен доступу к черновику и хранится только в localStorage этого браузера.

Проверка на staging с настоящим PostgreSQL/S3: открыть ссылку без входа, загрузить несколько файлов, закрыть и вновь открыть браузер, увидеть сохранённые файлы, удалить один, отправить пакет, проверить запись `candidate_docs` и HR-просмотр, затем убедиться, что отправленные объекты не удаляются lifecycle. Отдельно проверить истёкшую сессию и ошибку S3. Локальные unit-тесты и сборка не заменяют интеграционный прогон.

Предыдущий endpoint пакетной загрузки `POST /v1/public/candidate-documents/{token}` теперь возвращает 410 с предложением обновить страницу; старым клиентам требуется обновление frontend. Существовавшие Base64-черновики не мигрируют автоматически: старая запись удаляется при открытии страницы. Кандидату потребуется повторно выбрать эти файлы.
